The daily-snapshot cron moves to the root `vercel.json`. `backend/vercel.json` and `frontend/vercel.json` are removed — the root file is now the only Vercel config. Same-origin in production means the frontend's API base URL becomes a relative `/api/v1` (set via the frontend service's `VITE_API_URL` build env var) instead of an absolute cross-origin URL; `docker compose` local dev is unaffected (`VITE_API_URL=http://localhost:8000/api/v1` unchanged). CORS_ORIGINS no longer needs the production frontend URL added, since same-origin requests don't trigger CORS at all — it still matters for local dev (`http://localhost:5173`). NullPool + Neon `sslmode=require` in backend/db/session.py are unaffected and already correct. Note: Vercel Services has no literal `"public": true` field — a service becomes publicly reachable purely by being the `destination` of a top-level rewrite; verified against current Vercel docs (vercel.com/docs/services, /docs/services/routing, /docs/services/config-reference) rather than assumed — Aayush
